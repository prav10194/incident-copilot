# Incident Copilot

AI copilot for production incident triage. Given a new incident, it retrieves
similar past incidents and runbooks, proposes a root cause **with citations**,
drafts an ITIL-style post-mortem, and suggests a remediation that a human must
approve before anything runs.

All data in this repo is **synthetic** and generated by `data/generate.py`.

## Setup

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python data/generate.py
```

## Why this exists

Incident triage is a retrieval problem before it is a reasoning problem: the
answer is usually in a past incident or a runbook. This project measures how
well retrieval actually works before adding an agent on top of it.
